# GAP3/CHEVIE parking functions

This library computes noncrossing parking functions, support restrictions, characters, cyclic actions, and coset-poset data. It requires GAP3 with Jean Michel's CHEVIE distribution. GAP4 alone does not provide this interface.

Start GAP3 with the current directory set to this package's directory: the folder containing `gap3/`, `wolfram/`, and this `docs/` directory. Then run:

```gap
Read("gap3/init.g");
ctx := NCContext(ComplexReflectionGroup(4), false);;
NCParkingCount(ctx, 2, ctx.nc);             # 169
NCParkingCharacter(ctx, ctx.W.identity, 2, ctx.nc);  # 169
```

From the package directory, run a complete example with the following command, replacing `/path/to/gap3/bin/gap.sh` with your GAP3 launcher:

```bash
"/path/to/gap3/bin/gap.sh" -q <<'GAP'
Read("gap3/examples/g4.g");
quit;
GAP
```

`Read("gap3/examples/restricted.g");` runs support, rank-filter, and topology examples.

## Context and conventions

`NCContext(W, word)` creates explicit state for one finite irreducible reflection group and one Coxeter element. Pass `false` to use CHEVIE's default word, or a generator-index list such as `[1,2]`. The implementation checks that the resulting dual factorization has length `Rank(W)`, generates `W`, and that the element has order `h = Maximum(ReflectionDegrees(W))`. CHEVIE can reject groups for which the required dual monoid is unavailable. These checks do not turn an arbitrary input word into a certified Coxeter word; supply a genuine Coxeter word for the intended finite well-generated group.

Important context fields are:

| Field | Meaning |
| --- | --- |
| `ctx.W`, `ctx.c`, `ctx.h` | Group, chosen Coxeter element, maximum reflection degree |
| `ctx.nc` | Elements of the noncrossing interval `[1,c]` |
| `ctx.levels` | CHEVIE's divisors grouped by rank |
| `ctx.ranks[i]` | Mathematical rank of `ctx.nc[i]`; identity has rank zero |
| `ctx.simpleGenerators` | Reflections in `AsWord(ctx.braid(ctx.c))`, used to define support |

A chain is `[x1,...,xk]` with `x1 <= ... <= xk` in absolute order. Repeated entries are allowed. `k` must be a positive integer; zero and negative values raise an error. There is no artificial upper bound on `k`.

A parking function is `[L, chain]`, where `L` is a **left** coset `g * W_(x1)`. The associated subgroup is generated by dual atoms below `x1`. The group `W` acts on the coset label by left multiplication and leaves the chain fixed. Records retain the chain, even if two cosets happen to be equal as sets.

`terminalElements` below is a list of allowed **largest** chain entries. Use `ctx.nc` for ordinary parking functions. Duplicate allowed endpoints are removed; an empty endpoint list produces no chains or parking functions.

## API

| Function | Result |
| --- | --- |
| `NCChains(ctx,k,terminalElements)` | All allowed length-`k` chains |
| `NCChainsStarting(ctx,k,x)` | All length-`k` chains beginning with `x` |
| `NCChainCounts(ctx,k,terminalElements)` | Counts indexed by the first element in `ctx.nc` |
| `NCParkingFunctions(ctx,k,terminalElements)` | Explicit `[coset,chain]` records |
| `NCParkingCount(ctx,k,terminalElements)` | Count without listing parking functions |
| `NCParkingCharacter(ctx,w,k,terminalElements)` | Number fixed by `w` |
| `NCCharacterTable(ctx,k,terminalElements)` | Character values and class representatives |
| `NCFixedSpaceDimension(ctx,w)` | Exact kernel dimension of `MatXPerm(W,w)-I` |
| `NCParabolic(ctx,x)` | Subgroup associated to `x` |
| `NCFullSupport(ctx,domain)` | Elements outside all proper subgroups generated by subsets of `ctx.simpleGenerators` |
| `NCFullSupportReflections(ctx)` | Full-support noncrossing dual atoms |
| `NCSupportIntersectionReport(ctx,domain)` | Boolean result and complete counterexample records for support intersections |

For full-support parking functions:

```gap
full := NCFullSupport(ctx, ctx.nc);;
NCParkingCount(ctx, 2, full);              # 81 for G4
NCParkingCharacter(ctx, ctx.W.identity, 2, full);
```

Support depends on `ctx.simpleGenerators`, so retain the same context when comparing runs. The code checks membership in all proper subgroups generated by subsets of this set, rather than assuming support intersections hold.

To test support intersections in the NC interval or the whole group:

```gap
NCSupportIntersectionReport(ctx, ctx.nc);
NCSupportIntersectionReport(ctx, Elements(ctx.W));
```

Each witness contains the two generating subsets, their intersection, and the elements violating the tested inclusion. Only unordered subset pairs are visited, because the assertion is symmetric.

For the rank-filter explorations, select endpoints directly:

```gap
ends := Filtered(full, x -> ctx.ranks[NCIndex(ctx,x)] >= 2);;
List([1..4], k -> NCParkingCount(ctx,k,ends));
```

Rank filters are configurable numerical experiments; a rank threshold is not asserted to produce a degree-shift formula in general.

## Cyclic action

The implemented `W x C` action is defined for **k=1**. With `q = c^d`, it sends

```text
[g * W_x, [x]] -> [w * g * q^-1 * W_y, [y]],  y = q * x * q^-1.
```

| Function | Result |
| --- | --- |
| `NCCyclicAction(ctx,w,d,parking)` | Explicit action on one `k=1` record |
| `NCCyclicFixedCount(ctx,w,d)` | Fixed-point count without constructing all parking records |
| `NCCyclicCharacterTable(ctx)` | Values on every class and every power, including power zero |

This convention follows [Definition 3.4 of *Parking Spaces for Complex Reflection Groups*](https://arxiv.org/html/2502.01970v1#S3.SS1). `d` may be any integer, and the table visits all residues modulo the order of `c`. The order-`k*h` Fuss rotation for `k>1` is not implemented.

## Numerical formula comparisons

The following helpers return the actual numbers and proposed numbers together. A successful finite calculation is evidence for that case, not a general proof:

```gap
NCCharacterComparison(ctx, 2, ctx.nc, 1);
NCCharacterComparison(ctx, 2, full,
    1 - Minimum(ReflectionDegrees(ctx.W)));
NCCyclicComparison(ctx);
NCFullSupportProducts(ctx);
```

`NCCharacterComparison` tests `(k*h+shift)^dim(V^w)`. `NCCyclicComparison` tests `(h+1)^dim ker(w-zeta^d I)` with `zeta = E(Order(W,c))` and the action convention above. Kernel dimensions come from exact matrices; reflection length is not used as a general replacement for codimension.

`NCFullSupportProducts` returns codegree products as named candidate values. It counts full-support **noncrossing** reflections (dual atoms), which need not be all ambient reflections. Filtering the zero codegree avoids assuming it is first in CHEVIE's list; the intended irreducible setting has one zero codegree.

## Optional topology export

`NCCosetPosetData(ctx,true)` returns the distinct cosets as sets and every strict inclusion `[i,j]` with the `i`th set contained in the `j`th set. It removes the whole-group coset. Pass `false` to include it. These relations are all comparabilities, not just Hasse edges.

Export the poset for a separate Sage computation:

```gap
NCWriteSagePoset(ctx, true, "parking-poset.sage");
```

Run `sage parking-poset.sage` to construct the poset, its order complex, and integral homology. The exported integer labels index the elements returned by `NCCosetPosetData`; GAP3 does not itself compute homology here.

## Verification and scale

Run `Read("gap3/tests/regression.g");` from GAP3 in the package directory. Tests compare dynamic programming with explicit chains, parking records, class fixed-point enumeration, cyclic action, action composition, support intersections, and proper coset inclusions. The regression groups are `A2`, `G4`, `G5`, and `G6`, with a separate `A3` character check and explicit-word setup check. Formula comparisons are checked only on these examples.

Tested with GAP3 `lib:07 Jan 2024, src:19 Mar 2021, sys:macosx gcc64`. This installation emits an existing `DisplayPresentation` warning in its own `fptietze.g`; no warning comes from these package files. The main regression script prints `ALL GAP3 REGRESSION TESTS PASSED` on success. GAP3 can enter an error loop yet still exit with status zero, so check that marker and inspect errors.

Explicit chain and parking enumeration grows rapidly. Prefer counts and characters for larger `k`. Contexts cache order comparisons, subgroups, and cosets; all-pair support checks and topology export are intended for small groups. Do not mutate cached fields.
